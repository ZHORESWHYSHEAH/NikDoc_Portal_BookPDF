Access Principles

The NikDoc Secure Document Distribution portal operates on a **zero-trust link access model**. Recipient authentication relies entirely on highly random, non-guessable URLs generated on this panel. If a user's link is revoked, their authorization token is instantly deleted from the local database, denying any subsequent download or stream queries. Every document access, token generation, and failed request is logged server-side for comprehensive auditing.
